📖 Theorie

FFTjax solves variational partial differential equations on voxelized domains using a spectral Fourier-based approach.

Spectral solution of PDEs​

Consider a generic equilibrium problem in small-strain elasticity:

∇⋅σ(x)=0\nabla \cdot \sigma(\mathbf{x}) = 0∇⋅σ(x)=0

with constitutive relation

σ=C:ε,ε=12(∇u+∇u⊤)\sigma = \mathbb{C} : \varepsilon, \qquad \varepsilon = \frac{1}{2}(\nabla u + \nabla u^\top)σ=C:ε,ε=21​(∇u+∇u⊤)

In the spectral approach, fields are transformed into Fourier space:

f^(k)=F[f(x)]\hat{f}(\mathbf{k}) = \mathcal{F}[f(\mathbf{x})]f^​(k)=F[f(x)]

Spatial derivatives become multiplications:

∇→ik\nabla \rightarrow i\mathbf{k}∇→ik

which converts differential operators into algebraic expressions. The equilibrium equation is then solved iteratively in Fourier space using a Green operator formulation, enabling efficient convolution-based updates.

The computational complexity scales as O(Nlog⁡N)\mathcal{O}(N \log N)O(NlogN) due to the use of Fast Fourier Transforms.

Mechanical solver formulations​

FFTjax provides two Newton-CG solvers for the mechanical equilibrium problem (solvers/mechanical/), differing in which field is the CG unknown.

Strain-based (strain_nw_cg.py, Vondřejc et al. 2014 / Lucarini & Segurado 2018). The unknown is the periodic strain fluctuation Δε\Delta\varepsilonΔε. Equilibrium is enforced through a fixed reference-medium Green's operator Γ^0(ξ)\hat{\Gamma}_0(\boldsymbol{\xi})Γ^0​(ξ) (isotropic, "standard" or Willot "rotated" discretisation):

A(Δε)=F−1 ⁣[Γ^0:F[C:Δε]],b=−F−1 ⁣[Γ^0:F[C:ε0−σgoal]]A(\Delta\varepsilon) = \mathcal{F}^{-1}\!\big[\hat{\Gamma}_0 : \mathcal{F}[\mathbb{C}:\Delta\varepsilon]\big], \qquad b = -\mathcal{F}^{-1}\!\big[\hat{\Gamma}_0 : \mathcal{F}[\mathbb{C}:\varepsilon_0 - \sigma_{\text{goal}}]\big]A(Δε)=F−1[Γ^0​:F[C:Δε]],b=−F−1[Γ^0​:F[C:ε0​−σgoal​]]

Γ^0\hat{\Gamma}_0Γ^0​ only ever appears in even powers of ξ\boldsymbol{\xi}ξ (e.g. ξiξj\xi_i\xi_jξi​ξj​), which is what makes the CG operator provably symmetric positive-definite for arbitrarily heterogeneous C(x)\mathbb{C}(\mathbf{x})C(x), and is why it needs no extra preconditioning beyond the reference medium itself.

Displacement-based (displacement_nw_cg.py). The unknown is instead the periodic displacement fluctuation u^\hat{u}u^ itself, with the strain built directly from its symmetric gradient in Fourier space, ε^=12(iξ⊗u^+sym.)\hat{\varepsilon} = \tfrac{1}{2}(i\boldsymbol{\xi}\otimes\hat{u} + \text{sym.})ε^=21​(iξ⊗u^+sym.), and the true (possibly heterogeneous) tangent C(x)\mathbb{C}(\mathbf{x})C(x) applied with no reference-medium approximation. Because ξ\boldsymbol{\xi}ξ now appears to an odd power, the Nyquist frequency component must be zeroed on even grid dimensions to preserve the Hermitian symmetry a real-input FFT requires — an FFT-Galerkin-specific correction not needed by the Green's-operator formulation. Convergence for realistic (high-contrast) composites additionally needs a frequency-domain preconditioner (ξ⋅C0⋅ξ)−1(\boldsymbol{\xi}\cdot\mathbb{C}_0\cdot\boldsymbol{\xi})^{-1}(ξ⋅C0​⋅ξ)−1 built from a reference stiffness C0\mathbb{C}_0C0​.

Mixed strain/stress boundary conditions. Both formulations can prescribe macroscopic strain on some tensor components and macroscopic stress on others (e.g. a free-lateral-surface uniaxial-stress test), selected via a (3,3) control mask. The two schemes solve this differently:

  • The displacement-based solver embeds the stress-controlled average-strain correction directly as an extra unknown in the zero-frequency mode of the strain field, coupled to the fluctuation field through the same symmetric CG operator — valid for arbitrary (including heterogeneous) materials.
  • The strain-based solver can instead reclaim the Green's operator's own (otherwise always-zero) DC block for this purpose (dstrain_nw_cg_mixed), which is cheaper but only symmetric — and therefore only a valid one-shot CG solve — for homogeneous materials; for heterogeneous materials the mixed-BC CG operator loses symmetry and the displacement-based solver must be used instead.

Variational formulation​

The solver is based on an energy minimization principle. For elasticity and phase-field fracture, the total energy functional reads

Π(u,d)=∫Ωg(d) ψe(ε(u)) dΩ+∫ΩGc(d22ℓ+ℓ2∣∇d∣2)dΩ\Pi(u, d) = \int_\Omega g(d)\,\psi_e(\varepsilon(u)) \, d\Omega + \int_\Omega G_c \left( \frac{d^2}{2\ell} + \frac{\ell}{2} |\nabla d|^2 \right) d\OmegaΠ(u,d)=∫Ω​g(d)ψe​(ε(u))dΩ+∫Ω​Gc​(2ℓd2​+2ℓ​∣∇d∣2)dΩ

where

  • uuu is the displacement field
  • ddd is the phase-field variable
  • g(d)g(d)g(d) is the degradation function
  • Gc\mathcal{G}_cGc​ is the fracture toughness
  • ℓ\ellℓ is the length scale parameter

Staggered solution scheme​

A variational staggered scheme is employed:

  1. Elastic step
    Minimize Π(u,dn)\Pi(u, d^{n})Π(u,dn) with respect to uuu → Linear/nonlinear equilibrium solved via spectral operator.
Au u=bu,A_u \, u = b_u ,Au​u=bu​,

where AuA_uAu​ represents the spectral stiffness operator. The system is solved iteratively using the Conjugate Gradient (CG) method, exploiting the matrix-free application of AuA_uAu​ in Fourier space.

  1. Phase-field step
    Minimize Π(un+1,d)\Pi(u^{n+1}, d)Π(un+1,d) with respect to ddd
    → Helmholtz-type equation solved in Fourier space.
Ad d=bd,A_d \, d = b_d ,Ad​d=bd​,

which is likewise solved using CG with spectral evaluation of the differential operators.

The two fields are updated alternately until convergence of the coupled system.

Image-based discretization​

The computational domain is defined on a regular voxel grid derived from segmented experimental data. Material heterogeneity is directly assigned per voxel, avoiding geometric idealization and enabling direct microstructure-to-simulation coupling.

Periodic boundary conditions are naturally satisfied within the spectral framework.

This formulation enables:

  • Efficient voxel-scale simulations
  • Direct use of image-based microstructures
  • Differentiability for inverse parameter identification
  • GPU acceleration via JAX
