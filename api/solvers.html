class solvers.types.SolveState(strain_loc, stress_loc, tangent_glob, strain_ave, stress_ave, strain_ave_inc_goal, stress_ave_inc_goal, Deltastrain_loc, Deltastress_loc, stress_loc_goal, deltastrain_loc, time, dtime, kinc, kstep, iter_nw, iter_cg, info, bb0n, pnewdt)​

Bases: NamedTuple

Evolving state for one variational NW-CG elastic solve.

A NamedTuple so it is automatically a JAX pytree — safe to pass through jax.jit, lax.while_loop, lax.scan, etc.

Precomputed operators (G_glob, C_field) are intentionally excluded; they are static and should be passed as separate arguments to the solver.

class solvers.types.SolverSettings(ndim, n, L, toler_lin=1e-07, toler_nw=1e-07, maxiter_cg=1000, maxiter_nw=6, control=, strain_ave_goal=, stress_ave_goal=, timer=, jobname='', output='')​

Bases: object

Static configuration for the variational NW-CG elastic solver.

Passed once at setup; nothing here changes during iteration. Load steps are accumulated by calling add_load_step().

  • Parameters:
    • ndim (int)
    • n (tuple *[*int , ... ])
    • L (tuple *[*float , ... ])
